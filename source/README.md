# 热流指挥官：换热站危机

《化工原理 A(I)》第四章 AI 作业：与传热内容相关的互动游戏。

## 核心知识点

- 换热器并流与逆流的传热差异
- 热量守恒与传热速率关系
- 污垢热阻对总传热系数的影响
- 强化传热与泵耗之间的工程权衡
- 换热器运行参数的综合调度

游戏选择“换热器及传热强化”作为核心知识点，同时把第四章“传热过程计算”作为数值模型基础。

## 运行方式

直接双击 `index.html`，使用现代浏览器打开即可。

- 无需安装依赖
- 无需联网
- 无外部图片、字体或 CDN
- 支持电脑投屏与手机浏览器

## 游戏操作

1. 点击“进入中控室”。
2. 阅读任务简报，点击“开始调节”。
3. 使用右侧控制台调整流量、换热面积、流动方向和强化传热状态。
4. 点击“提交运行方案”或按 Enter 结算本关。
5. 完成五关后播放综合结算动画，并生成运行报告。

知识手册可以随时通过右上角书本按钮打开。

## 数值模型

模型使用冷、热两侧热容和 ε-NTU 关系计算换热器出口温度：

```text
C_h = m_h · c_p,h
C_c = m_c · c_p,c
Q_max = C_min · (T_h,in - T_c,in)
Q = ε · Q_max
```

总传热能力 `UA` 受有效面积、冷流体流量、污垢热阻和强化传热组件影响。泵耗则随冷流体流量近似三次方增长，并计入面积和强化组件带来的附加阻力。

这是用于课堂互动的教学简化模型，不替代 Aspen、HTRI 或严格工程设计计算。

## 设计说明

- 五个关卡分别覆盖：流向判断、负荷调节、污垢危机、强化传热、峰值综合调度。
- 参数调整会实时改变 Canvas 中的流体粒子、热场、污垢层和运行指标。
- 最终结算包含粒子汇聚、数字滚动、评级揭示、指标增长和运行报告。
- 动画尊重操作系统的“减少动态效果”设置，也可以手动跳过。
- 音效由 Web Audio API 实时合成，没有外部音频资源。

## 可复用与扩展

关卡配置集中在 `game.js` 顶部的 `MISSIONS` 数组中。每关包含任务说明、初始参数、锁定控件、目标区间、原理说明和报告文字，可以直接修改或扩展。
